# Governance

Stop the BPB workstream if implementation requires:

- copying or translating upstream `.proto` files or generated bindings;
- committing or distributing SDK-derived schemas, descriptors, or caches;
- coupling raw collection to schema or decoder availability;
- guessing an unknown device-path schema;
- redefining protobuf payload fields as project-owned public semantics;
- using decoded metadata to weaken cleanup evidence or path checks;
- claiming device, firmware, or schema compatibility without reproducible
  fixture evidence.

Completion requires all tracker items, public checks, applicable licensed local
contracts, restricted-artifact audit, and public documentation updates.
